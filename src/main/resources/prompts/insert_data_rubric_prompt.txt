Ban la chuyen gia cham diem SQL cho he thong thi thuc hanh CSDL.
Phan tich cau lenh INSERT SQL ben duoi va tao rubric theo KIEU TRU DIEM.

=== CAU HOI ===
%s

=== SQL DAP AN MAU ===
%s

=== TONG DIEM ===
%.2f diem

=== YEU CAU DAU RA ===
Tra ve DUNG JSON, khong markdown, khong giai thich:
{
  "total_points": %.2f,
  "question_category": "INSERT_DATA",
  "grading_payload": {
    "grading_settings": {
      "syntax_error_action": "PARTIAL",
      "allow_extra_rows": false,
      "penalty_per_extra_row": 0.1,
      "ignore_column_order": true,
      "trim_string_spaces": true,
      "case_insensitive_data": false
    },
    "tables": [
      {
        "table_name": "<TEN_BANG>",
        "table_points": <diem_toi_da_cua_bang>,
        "row_grading_strategy": "<PARTIAL_BY_COLUMN|ALL_OR_NOTHING>",
        "missing_row_penalty": <muc_tru_khi_thieu_1_dong>,
        "columns_config": [
          {
            "name": "<TEN_COT>",
            "is_primary_key": <true_or_false>,
            "points": <muc_tru_khi_cot_nay_sai>,
            "match_type": "<EXACT|IGNORE_CASE_AND_SPACE|NUMERIC_TOLERANCE>"
          }
        ],
        "expected_data": [
          {
            "<TEN_COT_1>": "<GIA_TRI>",
            "<TEN_COT_2>": <GIA_TRI>
          }
        ]
      }
    ]
  }
}

=== QUY TAC BAT BUOC (DEDUCTION) ===
- Day la rubric TRU DIEM, KHONG phai rubric cong diem.
- table_points la diem toi da cua bang.
- Bai lam bat dau tu diem toi da, sai dau tru do.
- Thieu 1 dong tru missing_row_penalty.
- Neu row_grading_strategy = PARTIAL_BY_COLUMN:
  moi cot sai tru theo columns_config[].points cua cot do.
- Neu row_grading_strategy = ALL_OR_NOTHING:
  sai 1 cot trong dong thi tru missing_row_penalty cho dong do.
- Gia tri columns_config[].points phai > 0 cho cac cot duoc cham.
- Mỗi bang phai co it nhat 1 cot PK (is_primary_key=true) de doi chieu dong.
- Tong table_points cua tat ca bang phai bang %.2f (cho phep lech toi da 0.01 do lam tron).

=== QUY TRINH ===
1. Liet ke tat ca bang co INSERT trong SQL dap an.
2. Trich day du expected_data cho tung bang.
3. Chon cot PK hop ly de match dong.
4. Gan row_grading_strategy:
   - PARTIAL_BY_COLUMN cho bang co nhieu cot can cham.
   - ALL_OR_NOTHING cho bang can dung tron dong.
5. Phan bo table_points hop ly va dam bao tong dung bang tong diem cau hoi.
6. Tra ve JSON hoan chinh.

=== KIEM TRA TRUOC KHI TRA VE ===
- Khong thieu bang nao trong tables[].
- Moi bang co table_name, table_points, missing_row_penalty, columns_config, expected_data.
- Moi cot trong columns_config co name, is_primary_key, points, match_type hop le.
- table_points > 0 va missing_row_penalty > 0.
- Tong table_points = total_points.
- Chi tra ve JSON.
